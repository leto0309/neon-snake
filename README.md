# 霓虹貪食蛇 NEON SNAKE

一款霓虹風格的貪食蛇小遊戲，只有一個 HTML 檔案，不需要安裝任何套件或建置工具。

## 怎麼玩

吃掉粉紅色的光點讓蛇變長，每吃一個得 10 分，蛇也會越跑越快。撞到牆壁或自己的身體就結束；把 20×20 的場地完全填滿就獲勝。

最高分會儲存在瀏覽器的 `localStorage`，重新整理頁面後仍會保留。

## 操作方式

| 按鍵 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移動（在開始畫面按下也會直接開始） |
| `空白鍵` | 開始／暫停／繼續 |
| `Enter` | 開始新的一局 |
| 手機滑動 | 在畫面上滑動來轉向 |

## 執行方式

直接用瀏覽器開啟 `index.html` 即可。

如果想用本機伺服器開啟，也可以在專案資料夾執行：

```bash
python -m http.server 8000
```

然後前往 <http://localhost:8000>。
